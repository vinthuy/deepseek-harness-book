# DeepSeek Harness 入门指南：从使用到理解

> 从零开始理解并动手使用 DeepSeek Harness（DSH）——一个"一切皆插件"的 Agent 运行时与框架。
> 这本书不仅是教程，更是一次对现代 Coding Agent 系统的设计解剖：它为什么长这样、它解决了什么、代价是什么、未来会走向哪里。

本书基于 `deepseek-ai/deepseek-harness` 源码撰写，版本基准 **`0.1.5-rc.2`**（packages 下 268 个包，含 vendor/apps 等共 290 个 workspace 包）。目标读者是：

- 听说过 Agent Harness、想弄明白它和"模型/API/Agent 框架"有什么区别的开发者；
- 想在本地跑起 DSH、读懂它的插件机制并开始写自己插件的工程师；
- 想理解现代 Coding Agent 系统如何设计（事件溯源、能力接缝、沙箱、类型安全 RPC）的架构学习者；
- **以及**——想透过一个具体产品，思考"Agent 时代的基础设施应该长什么样"的思考者。

## 这本书的双重身份

**它是一本入门教程。** 第 1-2 章带你建立概念、把环境跑起来；每章都有可执行的动手实验，附录有命令速查和术语表。只想知道"怎么用"，顺着阅读路线走即可。

**它也是一本设计分析书。** 每一章都不止于"是什么、怎么用"，而是回答三个更深的问题：

1. **为什么这么设计？** —— 这个机制在解决什么问题？有哪些备选方案，为什么选它？
2. **代价是什么？** —— 每种设计都有权衡：复杂度的代价、性能的代价、信任的代价。
3. **它会走向哪里？** —— 这个设计在更大的技术演进中处于什么位置，未来可能怎么变？

为此，本书每章包含两类特殊内容：

- **「设计思考」**：把该章的核心机制放在更大的背景里（历史、同类系统、行业趋势）做对照分析；
- **「思考题」**：每章末尾的开放问题，没有标准答案，目的只是让你带着问题去读源码、去验证、去形成自己的判断。

代码在本书中是**插图而非教材**：只出现那些能说明设计意图的最小骨架，帮助你"读懂"而非"抄写"。

全书配有 **Mermaid 架构图/时序图**（GitCode 渲染），关键的架构、时序、流程都有一图胜千言的可视化。

```text
路线 A：快速上手（半天，纯使用）

  第 15 章   展望                    把前面所有章节串成一条演进主线

  附录 A 术语表 · B 命令速查 · C 参考资料 · D 插件实战 · E 思考题提示
```

每章的**动手实验**都基于真实仓库，建议边读边在 `deepseek-harness` 仓库里操作；每章的**思考题**不需要立即回答——它们会在后面的章节里以新的角度再次出现。

## 环境要求

- Node.js `^22.19.0 || >=24.0.0`（本书示例使用 v24）
- pnpm（推荐通过 `corepack pnpm` 调用，仓库锁定 `pnpm@11.7.0`）
- 一个 DeepSeek API Key（跑真实模型时需要；不跑模型也能完成绝大多数章节的练习）
- Git、能访问 GitHub/npm registry 的网络

## 与官方文档的关系

本书是**面向入门者的引导式教程 + 设计分析**，不是官方文档的翻译。官方仓库内已经有非常完整的文档体系：

- `docs/architecture.md`：架构总览
- `docs/cordis-primer.md`：Cordis 五分钟入门
- `docs/user/develop/basic/`：开发者的分步教程（配置、工具、发布）
- `docs/cookbook/`：专题配方（加工具、加 LLM 适配器、加对话节点等）
- `docs/subsystems/`：子系统深度文档（会话、沙箱、Typert……）
- `docs/glossary.md`：术语表

建议分工：**本书负责"建立心智模型与设计直觉"**，官方文档负责"查细节、跟最新"。遇到不一致，以仓库源码为准。

## 本书约定

- 命令默认在 `deepseek-harness` 仓库根目录执行（本书以 Windows PowerShell 为例）；
- 因为本机没有全局 pnpm，所有 pnpm 命令统一写作 `corepack pnpm ...`；
- 代码示例为教学简化版，可能与仓库内生产代码略有出入，以仓库源码为准；
- 仓库演进很快，存在破坏性变更，遇到对不上的地方先 `git pull`。
